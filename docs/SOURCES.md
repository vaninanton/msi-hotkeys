# Внешние источники и что каждый из них дал

Проверено 2026-10-02. Значения из открытых проектов приняты за истину.

## 1. drivers/platform/x86/msi-wmi.c (майнлайн)

[Исходник](https://git.kernel.org/pub/scm/linux/kernel/git/torvalds/linux.git/tree/drivers/platform/x86/msi-wmi.c),
GPL-2.0, копии в этом репозитории нет. Таблица скан-кодов кнопок. Младший байт
нашего кода совпадает с её значениями, отсюда имена тачпада (`0x08`, Fn+F3) и
камеры (`0x57`, Fn+F6). GUID события совпадает дословно.

## 2. drivers/platform/x86/msi-laptop.c (майнлайн)

Флаги EC для управления кнопками:

| Адрес | Что |
|---|---|
| `0x2d` бит 0 | SCM load — обработку кнопок берёт ОС |
| `0x2e` биты 0, 1, 3, 4 | Bluetooth, камера, WLAN, 3G |
| `0x2f` | какие устройства присутствуют |
| `0x33` бит 0 | автоматическое управление вентилятором |
| `0xe4` биты 1, 3, 4 | Turbo, ECO, тачпад |

## 3. BeardOverflow/msi-ec — карты регистров по моделям

Конфигурации для платы 1796 нет, описаны машины новее. Полезное:

| Поле | Адрес | Бит / значения |
|---|---|---|
| `cooler_boost` | `0x98` | бит 7 |
| `cpu.rt_temp` / `cpu.rt_fan_speed` | `0x68` / `0x71` | — |
| `gpu.rt_temp` / `gpu.rt_fan_speed` | `0x80` / `0x89` | — |
| `shift_mode` | `0xd2` | turbo `0xc4`, eco `0xc2`, comfort `0xc1` |
| `fan_mode` | `0xd4` | auto `0x0d`, silent `0x1d`, advanced `0x8d` |
| `charge_control` | `0xd7` | — |
| `webcam` | `0x2e` / блок `0x2f` | бит 1 |
| `super_battery` | `0xeb` | маска `0x0f` |

**Статус Cooler Boost в контроллере есть** — `0x98` бит 7. Мы его не нашли
потому, что окна `MSI_*` этого адреса не покрывают.

## 4. msi-ec, обсуждение #98 — разметка блоков WMI

Количества экземпляров блоков, выложенные для другой машины, **совпадают с
нашими до единицы по всем девяти**: Software 34, Device 4, Power 3,
Master_Battery 16, Slave_Battery 14, CPU 19, VGA 18, System 21, AP 8.
Notify id у всех `0x41`.

Отсюда важное: **разметка этих окон не специфична для модели.** Всё, что
сообщество выяснит про эти байты на любой машине MSI, переносится на нашу.

Там же расшифровано имя прошивки `1796EMS1.104`: `1796` — кодовое имя платы,
`EMS` — контроллер ENE (`IMS` означал бы ITE), `1` — ревизия платы, `104` —
версия. И замечание про адреса: у Intel 10-го поколения и новее настройки
сдвига, подсветки и вентилятора лежат на `0xD_`, у AMD — на `0xF_`.

## 5. Documentation/wmi/devices/msi-wmi-platform.rst (майнлайн)

Описывает **методы**, а не свойства:

- `Get_EC()` — флаговый байт и **28-байтовая строка версии прошивки**;
- `Get_Fan()` — до четырёх 16-битных показаний big-endian, `RPM = 480000 / значение`;
- `Get_WMI()` — версия интерфейса.

`Get_EC()` подтверждает нашу расшифровку `MSI_Software`: байты `[6…33]` — ровно
28 байт, и читаются как строка версии. На этой машине методов нет: проверены все
1605 классов в `root\WMI`.

## 6. wygodad/ghostdeck — управление EC через WMI без драйвера

Самый близкий к нам по способу доступа. Пишет в EC через класс `MSI_ACPI`,
метод `Set_Data`: буфер 32 байта, байт 0 — адрес регистра, байт 1 — значение.
Семейства: G2 — сдвиг `0xD2`, вентилятор `0xD4`, супербатарея `0xEB`; G1 —
сдвиг `0xF2`, вентилятор `0xF4`, заряд `0xEF`. Кривые на G2: CPU `0x6A`/`0x72`,
GPU `0x82`/`0x8A`.

**На нашей машине `MSI_ACPI` не зарегистрирован**, и ни у одного класса нет
методов `Set_Data`/`Get_Data`. Разница в происхождении: классы `MSI_*` приходят
из прошивки через ACPI-блок `_WDG`, а `MSI_ACPI` — программный провайдер,
который регистрируется MOF-файлом из состава MSI Center. Сама `msiapcfg.dll`
в системе есть (`SysWOW64`, 10864 байта), а MOF — нет, потому что стоял старый
SCM, а не MSI Center.

Отсюда возможный путь на будущее: достать MOF из установщика MSI Center и
зарегистрировать схему. Тогда произвольные адреса EC стали бы доступны без
ring-0 — включая статус обдува и настоящие кривые.

## 7. dmitry-s93/MControlCenter — не подошёл

Список проверенных устройств начинается с прошивок 2018–2019 годов
(`E16S1IMS.106`, `17G1EMS1.107`). Наша машина 2016 года старше всего, что там
описано.

## Чего по-прежнему нет ни в одном источнике

Смысл отдельных байтов внутри окон `MSI_AP`, `MSI_System`, `MSI_Power` и
`MSI_Device`. Соответствие индексов окон адресам EC тоже нигде не описано:
структурное сходство видно (у CPU одно «живое» показание температуры плюс
кривая из шести точек и шести значений — так и в msi-ec), но шаг индексов не
совпадает с шагом адресов, поэтому выводить одно из другого нельзя.
