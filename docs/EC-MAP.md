# Карта байтов EC этой машины

Получена из ACPI-таблицы самой машины, а не подбором. Инструменты разбора — в
[../tools/acpi/](../tools/acpi/), полная таблица — `tools/acpi/block-map.csv`.

## Как она получена

1. DSDT лежит в реестре (`HKLM\HARDWARE\ACPI\DSDT\MSI_NB\MEGABOOK\01072009`,
   141 723 байта) и читается без прав администратора.
2. Блок `_WDG` связывает GUID каждого класса `MSI_*` с идентификатором объекта:
   `AA` Software, `AB` Device, `AC` Power, `AD` и `AE` батареи, `AF` CPU,
   `AG` VGA, `AH` System, `AI` AP. Событие — объект `A`, флаги `0x09`.
3. Метод `WQ<id>` перечисляет поля EC, которые окно отдаёт, а `WS<id>` — те, что
   принимает. Область `EC__` объявляет эти поля по именам.
4. **Проверка разбора:** длина списка полей каждого метода совпала с числом
   экземпляров блока — 34 у Software, 4 у Device, 16 у батареи и так далее.

## Окна и адреса

| Окно | Индекс | Адрес EC | Что это |
|---|---|---|---|
| `MSI_Software` | `[0]` | `0x2D` бит 0 | **передача кнопок софту**: `MSI_STANDARD_EC_SCM_LOAD` из msi-laptop.c |
| | `[1]` | `0x2D` биты 1–4 | не определено; служба MSI меняет бит 1 |
| | `[2]`, `[4]`, `[5]` | `0xEE`, `0xE5`, `0xE6` | не определено |
| | `[3]` | `0x2D` биты 5–7 | не определено |
| | `[6…33]` | `0xA0…0xBB` | версия прошивки EC, ASCII, 28 байт |
| `MSI_Device` | `[0…3]` | `0x2E`, `0x2F`, `0x2B`, `0x2C` | `0x2E` биты: Bluetooth, камера, WLAN, 3G; `0x2F` наличие устройств |
| `MSI_Power` | `[0…2]` | `0x30`, `0xBC`, `0xBD` | `0x30`: источник питания, крышка, `KBCS` |
| `MSI_CPU` | `[0]` | `0x33` | бит 0 — автоматика вентилятора |
| | `[1]` | `0x68` | **температура CPU** |
| | `[2]`, `[3]` | `0x71`, `0x70` | по msi-ec — обороты CPU, **но на этой машине всегда 0** |
| | `[5…10]` | `0x6A…0x6F` | точки кривой: 60 65 70 75 75 75 |
| | `[12…17]` | `0x73…0x78` | обороты кривой: 50 56 66 76 76 76 |
| `MSI_VGA` | `[1]` | `0x80` | **температура GPU**, ноль пока карта обесточена |
| | `[2]` | `0x89` | по msi-ec — обороты GPU, **на этой машине всегда 0** |
| | `[5…10]` / `[12…17]` | `0x81…0x87` / `0x8B…0x90` | кривая GPU: 55 60 65 70 75 75 → 50 56 66 76 86 86 |
| `MSI_System` | `[0]`, `[1]` | `0xE4` биты 0–2 и 3–7 | бит 1 — Turbo (msi-laptop) |
| | `[2…20]` | `0xE7`, `0xF0…0xFD`, `0xE0`, `0xE3` | `0xF1` яркость, `0xFE`/`0xFF` подсветка от батареи и сети |
| `MSI_AP` | `[0…7]` | `0xCF…0xC8` | **соответствие под сомнением**, см. ниже |

## Батарея

Слова 16-битные, не байты. Сверено с данными Windows — совпало.

| Индекс | Адрес | Поле | Что это | Проверка |
|---|---|---|---|---|
| `[0]` | `0x31` | биты | 0 установлена, 1 заряжается, 2 разряжается, 3 заряжена | `0x05` при разряде, `0x09` при полной |
| `[1]` | `0x38` | `MDC` | проектная ёмкость, мА·ч | 3924 |
| `[2]` | `0x3A` | `MDV` | проектное напряжение, мВ | 10800 = 3 × 3,6 В |
| `[6]` | `0x42` | | заряд, % | 44 против 43 у Windows |
| `[7]` | `0x44` | `MFC` | полная ёмкость, мА·ч | 3561 × 10,6 В ≈ 37 762 мВт·ч против 37 951 |
| `[8]` | `0x46` | `MCU` | ток, мА, **со знаком** | −2220 при разряде |
| `[9]` | `0x48` | `MRC` | остаток, мА·ч | 1540 × 10,6 ≈ 16 324 против 16 405 |
| `[10]` | `0x4A` | `MVO` | напряжение, мВ | 10604 — совпало точно |
| `[11]` | `0x4C` | `MTE` | температура, десятые кельвина | 3062 → 33,05 °C |

Знак тока однажды сломал всю таблицу: функция преобразования отбрасывала
отрицательные значения, строка выпадала из окна, и весь хвост съезжал на
позицию. На зарядке ток неотрицателен, поэтому ошибка пряталась.

## Чему не верить

**`MSI_AP`.** Метод декодируется как `0xCF…0xC8`, но `0xCF` по именам прошивки —
это `ADP_` (адаптер) и `CHG_` (заряд), а `AP[0]` показывает ноль при работе от
сети. Значит порядок индексов в этом блоке прочитан неверно, хотя длина сошлась.

**Обороты по msi-ec.** Адреса `0x71` и `0x89` эта прошивка не заполняет: ноль
даже при слышимо работающем Cooler Boost. Карта адресов верна, содержимое — нет.

## Число вентилятора

`MSI_AP[2]`: покой около 77, максимум 137–138, между ними плавный спад через
тринадцать промежуточных значений за тринадцать секунд.

- **Измерение, а не команда.** Заданная кривая переключалась бы ступенями по
  своим значениям (50, 56, 66, 76), а не шла бы плавно.
- **Не формула ядра.** `RPM = 480000 / значение` даёт 6234 в покое и 3503 на
  бусте, то есть на бусте медленнее — бессмыслица.
- **Не проценты:** 138 больше ста.
- Простые множители правдоподобны: `×40` даёт 3080 и 5520, `×50` — 3850 и 6900.

Единица остаётся неизвестной. Определить её можно одним замером против любого
источника, читающего обороты напрямую (HWiNFO, Libre Hardware Monitor), — оба
требуют ring-0 драйвера, поэтому в проекте не используются.

Отдельно: ноль и разовые выбросы вроде 226 — это чтение регистра в момент
обновления, а не показание. Одиночные значения между устойчивыми соседями
следует отбрасывать.

## Что в прошивке есть, а в окнах нет

Статус Cooler Boost: по картам msi-ec это `0x98` бит 7, и ни одно из наших окон
этого адреса не покрывает. Штатных объектов вентилятора ACPI (`_FST`, `_FPS`)
в таблице нет вовсе; имя `CFAN` в DSDT — пустая глобальная переменная.
