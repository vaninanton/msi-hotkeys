# Опыты с записью в EC

Три скрипта, каждый по одной схеме: прочитать, записать, прочитать обратно,
20–25 секунд смотреть на тахометр, восстановить в `finally`. Нужна сессия
с правами администратора; лог пишется в `%TEMP%`.

| Скрипт | Что пишет | Итог 2026-10-20 |
|---|---|---|
| `fan-curve-raise.ps1` | кривая `MSI_CPU[12…17]` → 100 | принято, тахометр 75 |
| `fan-curve-advanced.ps1` | то же + `0xF4` → advanced, затем первая точка → 30 °C | принято, `0x71` стал 100, тахометр 75 |
| `fan-autofan-bit.ps1` | `0x33` бит 0 → 0 | принято, тахометр 75 |

Вывод: окна записываемы, вентилятор за записями не идёт. Разбор —
в `docs/FINDINGS.md`.
